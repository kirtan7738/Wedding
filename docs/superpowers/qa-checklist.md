# Real-device QA checklist — before sharing the link

Run on: **your Android in WhatsApp's in-app browser**, **an iPhone in WhatsApp + Safari**, **one older/cheaper Android**, **a laptop**. Open the link fresh each time (new tab / reopen from the WhatsApp chat).

## Opening
- [ ] Cover appears quickly; torans, garlands, diyas, gold seal and "આમંત્રણ ખોલો" are visible and nothing is cut off.
- [ ] One tap: seal glows, flap opens, card rises, petals + gold burst, warm glow, couple revealed — smooth, no freeze.
- [ ] "છોડો ›" skips straight to the invitation.
- [ ] Older phone: the opening still looks intentional (2D petals) and never freezes.
- [ ] Going back / reloading in the same tab does **not** replay the opening.

## Names & text
- [ ] પ્રિન્સી, પાર્થ, મંગલ પરિણય write in correctly and read naturally (ask a Gujarati reader).
- [ ] All Gujarati renders correctly (conjuncts ન્સ, ર્થ, ગ્ન; no boxes) — check the invitation patra word by word.
- [ ] With the phone's text size set large, nothing overlaps or gets cut off.

## Music (once the song file is added)
- [ ] Music starts with the tap, fades in, and the pill shows it playing.
- [ ] Switching to another WhatsApp chat / locking the phone pauses it; coming back resumes only if it was playing.
- [ ] The pill pauses/plays reliably.

## Sections
- [ ] Patra unrolls when reached; countdown tiles flip; moment cards and polaroids animate in once.
- [ ] Countdown shows the right days/hours (it counts to હસ્ત મેળાપ, 13 Dec 6:00 pm IST).
- [ ] "કેલેન્ડરમાં ઉમેરો" adds the event at 6:00 pm on 13 Dec.
- [ ] "દિશા જુઓ" opens Google Maps at the **right** Atithi Party Plot (after the real map link is added).
- [ ] Tapping a photo opens it large; tapping again closes it.
- [ ] "WhatsApp પર મોકલો" opens WhatsApp with the Gujarati message + link; "લિંક કોપી કરો" copies the link.

## Sharing
- [ ] Send the production link **to yourself first**: the preview card shows the red/gold image, title and date. If it is wrong, fix before anyone else receives it.
- [ ] QR code (`site/public/qr.png`) scans to the right link.
